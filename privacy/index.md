# Shik 隐私政策 V1.1

**运营主体** 蔡华燃（个人开发者）  
**联系邮箱** [madmanchr08@gmail.com](mailto:madmanchr08@gmail.com)

## 一、适用范围

Shik 是本地个人财务记录工具。使用普通记账功能无需注册 Shik 账户。Shik 不连接银行、支付宝或微信账户，不代你支付、转账、投资或进行其他金融交易。本版本使用本地账本及本地备份。

本政策说明设备本地处理的信息、Apple 及你所选服务处理的信息，以及运营主体因你主动联系客服而实际收到的信息。Shik 当前未接入广告、第三方分析或登录服务，不进行跨应用跟踪，没有运营主体控制的账本、截图识别或验单服务器。

## 二、设备本地处理的信息

你可主动录入账户、资产负债、余额、交易、分类、标签、预算、财务目标及备注，并设置显示名称、头像和应用偏好。Shik 使用这些信息保存账本、计算余额、展示统计、管理计划、提供本地备份和恢复，并在设备上作分类匹配。头像仅使用你主动通过系统选择器选择的照片。运营主体不会因你使用这些功能而收到上述数据。

### 账单导入、分类识别与 CSV 导出

你可通过系统文件选择器主动选择受支持的支付宝、微信或 Shik 账单文件。Shik 读取所选文件，在设备上解析和匹配账户、分类、收支方向和交易关系，并按现有记录和来源证据识别可能重复的账单。你可在预览中核对和修正日期、金额、交易对象、备注、账户、分类及退款或转账关系，确认后才提交符合条件的记录。选择云盘上的文件时，提供该文件的服务可能处理文件读取或下载请求。

预览可能读取交易对象、商品说明、支付方式、金额、状态、订单标识等原始字段。成功导入的本地记录可能附带批次、来源适配器及版本、来源标识摘要、业务指纹、导入时间及部分交易字段或分类证据，用于管理导入来源、避免重复和保留交易关系。具体字段依来源和交易类型而异，已保存的来源证据可能随交易及备份保留。提交前创建的本地安全备份独立于导入预览，保存情况见第五节。

你主动导出时，Shik 在本地按所选范围生成 CSV，经系统分享交给你选定的应用、文件位置或服务。完整备份通过系统文件导出器交付。CSV 与完整备份无 Shik 应用内密码加密。Shik 在相关分享结束路径尝试清理临时文件，异常退出时可能延后。接收方保存的文件及系统备份中的副本需在相应位置管理。

### 快捷指令截图记账

Shik 的「截屏记账」只接收快捷指令本次传入的一张受支持图片，例如你在快捷指令中选择或截取的支付截图。Shik 在设备内存中读取图像并生成去除源元数据的临时图像，使用 Apple Vision 在设备端执行文字识别，并准备可编辑草稿。识别可能涉及金额、时间、交易对象等。你可核对、修改或取消，在主动确认保存后相应交易字段才写入账本。原图不作为正式账单附件保存。

图像、识别结果与草稿由临时会话承载。完成、取消或会话失效会结束该会话，系统相册、快捷指令或其他应用持有的原图及副本需另行管理。为记录免费额度和防止同一保存操作被重复提交，设备另行保存操作标识、请求摘要、关联交易标识和额度使用记录。删除单笔交易或恢复普通账本不会返还已消耗次数。该技术记录不纳入普通账本备份，也不按固定天数自动清除。

### 敏感个人信息提醒

金融账户信息属于敏感个人信息。账单、银行账户名称、交易记录和支付截图还可能包含能识别你或他人的信息、交易对手和财务状况。处理这些字段是为了完成你请求的本地记账、来源核对或交易识别。泄露或误分享可能影响个人隐私和财产安全。请仅选择有权处理的文件，核对预览，并在导出、分享或反馈前遮挡与该操作无关的信息。请勿提交密码、验证码或完整银行卡号。账单导入、截图识别和主动分享均可自行选择，手动记账仍可使用。

## 三、Apple 与你选用的系统服务

**StoreKit。** Apple 通过 App Store 和 StoreKit 处理商品查询、付款、订阅续费和恢复购买。Shik 从 StoreKit 读取商品标识和展示价格，以及判断权益所需的交易标识、签名验证结果、订阅状态、有效期、退款或撤销信息，在设备上验证和更新 PRO 权益。Shik 不接收完整支付卡资料或 Apple 账户密码，也不会把本地账本交给 Apple 作购买验证。Apple 对其处理的账户、支付和交易资料适用自身政策。 [Apple 隐私政策](https://www.apple.com/cn/legal/privacy/)

**PRO 活动配置。** Shik 通过 HTTPS 从 GitHub Pages 读取公开的活动时间和优惠配置。请求不包含 Apple 账号、设备标识、购买交易、活动资格结果或账本数据。GitHub Pages 为安全目的记录并保存请求 IP 地址，由 GitHub 按其隐私政策处理。Shik 不将该请求用于广告、分析或跟踪。 [GitHub 隐私政策](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

**文件、照片、快捷指令及分享。** 你控制所选文件和照片、快捷指令传入的内容、分享目的地及分享对象。系统文件提供商、照片或快捷指令服务、设备备份、系统剪贴板和接收文件的其他应用可依设备设置及自身规则处理数据。你可在系统中管理相应权限和服务设置，也可在 Shik 中取消选择或保存。本政策的本地处理说明适用于 Shik 对上述数据的处理。

## 四、意见反馈及邮件处理

你可以在应用内填写反馈，也可以直接联系我们。可自行决定是否选取图片或附加诊断信息。诊断内容限于应用版本与构建号、iOS 版本、设备型号和系统语言，本应用不会自动附带财务记录。请在发送前检查正文、收件地址和附件，遮挡不必要的信息。

Shik 使用系统邮件编辑器生成草稿。你可编辑或取消，只有你主动点击发送后，邮件才会经所选发件账户及邮件服务传给你确认的收件方。运营主体收到的是你实际发到支持邮箱的发件地址及邮件信息、正文、你附加的截图或可选诊断，用于回复、排查故障和维护改进 Shik。若无可用系统邮件账户，可主动复制反馈文字及所含诊断至系统剪贴板，再自行选择用途，图片不会随该复制操作自动发送。

支持邮箱由 Google Gmail 提供。你主动发送的邮件及附件可能经 Gmail 或你选用的发件服务在中国大陆境外传输、存储、备份和处理。涉及的资料范围就是上述邮件信息和你主动提交的内容。你可通过支持邮箱向运营者行使权利，或按 Google 隐私政策所列途径向 Google 联系或提出适用权利请求。你可以选择不通过反馈邮箱提交信息，仍可使用账本。适用法律要求独立告知、单独同意或其他出境条件时，相关反馈路径须在履行这些要求后提供。生成草稿或点击发送本身不代替依法需要的单独同意。 [Google 隐私政策及联系渠道](https://policies.google.com/privacy)

## 五、信息保存与删除

- 本地账本、设置、名称和头像通常保留至你修改、删除或清除本地应用数据。可在相应功能中管理已有记录。
- 本地安全备份与正式交易独立，删除交易或结束导入不会同步删除备份。备份目录有保留和清理机制，可在备份中心管理可见备份。导出的 `.ledgerbackup` 不包含显示名称和头像。外部备份、系统备份、导出文件和邮件副本需在相应位置另行删除。
- 运营主体仅在处理问题、解决争议或履行法定义务所必需的最短期间内保存反馈邮件及附件，超过必要期限后及时删除或匿名化处理。邮箱访问限于运营主体本人。邮件服务商控制的技术副本和备份适用其自身删除安排。
- 取消订阅、订阅到期、退款或交易被撤销本身不会删除已有账本、设置或备份。

## 六、你的权利与信息安全

你可在支持相应操作的功能中查看、修改或删除本地数据，可使用导出和备份功能，也可撤回未来的反馈授权。对运营主体仍持有的反馈，可通过联系邮箱依法请求查阅、复制、更正、补充、删除、限制或拒绝处理，也可要求说明本政策。撤回不影响撤回前基于同意开展的合法处理。出于信息安全考虑，运营主体可能核对请求范围和必要身份信息，并依法答复。请勿为身份核验发送与请求无关的敏感信息。

Shik 采取合理措施减少不必要的处理并保护数据。请保护设备和 Apple 账户，将未加密的账单及备份保存在你信任的位置。如果你是未成年人的监护人，可以通过联系邮箱就有关反馈信息咨询或行使适用权利。
